# Sonara Music

Cloudflare Pages deployment with isolated order storage and protected administration.

Oferta independente da Sonara Music publicada no Cloudflare Pages.

- Checkout Pix via Asaas
- Painel em `/admin/`
- Pedidos isolados no namespace `sonara-music-orders`

As credenciais são configuradas somente como Secrets no Cloudflare Pages e não fazem parte deste repositório.
